# Security policy

## Supported versions

Only the latest released tag (`ghcr.io/nudgebee/kubewatch:latest`) and the
current `master` receive security fixes. Older tags are not patched.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Use GitHub's private vulnerability reporting:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue with enough detail to reproduce.

We will acknowledge the report within five working days and aim to issue
a fix or mitigation for confirmed vulnerabilities in a reasonable
timeframe depending on severity.

If you cannot use GitHub's reporting flow, contact
`security@nudgebee.com` instead.
