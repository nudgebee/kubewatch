# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc].

By participating in this project — opening issues, submitting pull
requests, commenting, or otherwise interacting with the community —
you agree to abide by its terms. The full text is canonical and lives
at the link above.

## Reporting

Report violations privately to **security@nudgebee.com**. Reports are
acknowledged within five working days. Reporter identity is kept
confidential.

For security vulnerabilities, see [SECURITY.md](./SECURITY.md) instead.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
